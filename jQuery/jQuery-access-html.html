Accessing HTML controls using jQuery

# is used as id-selector in jQuery.

.val() is used to get or set the value of form controls.

:checked select the one that is currently checked/selected.

.is(":checked") check whether that element is checked. Results a boolean value.

.text() handles text, while .html() handles text containing HTML tags.

The event tells you WHEN something should happen. The function tells you WHAT should happen.
