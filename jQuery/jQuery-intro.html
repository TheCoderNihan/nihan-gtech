jQuery Introduction

jQuery is a fast, lightweight JS library to make JS programming shorter.

You need to either download it or use CDN to include the jQuery library in the code.

The basic syntax is $(selector).action();
where $ → jQuery symbol
selector → HTML element (id, class, tag)
action() → What you want to do

Example : $document.ready()
'document' represents the entire HTML webpage ; 'ready()' ensures HTML page loads fully before jQuery runs.

# is used as the id-selector in jQuery.
