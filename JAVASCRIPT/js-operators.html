JS Operators

JS has arithmetic, assignment, comparision, logical, bit-wise, string operators etc.

Arithmetic Operators: Used for mathematical calculations.

Assignment Operators: Used to assign values.

Comparison Operators: Used to compare values and return true or false.

We have > , < , >= , <= for comparison.

== is only to check if value is equal , === checks value and type

Similar for != and !==

logical Operators: Used to combine conditions.

We have AND ( && ) , OR ( || ) and NOT ( ! )

Bitwise Operators: Used for bit-level operations.

Ternary Operator: Used as a shortcut for if...else.

Type Operator: Used to determine the data type of a value or variable.

String Operators: Used to concatenate (join) strings.
