JS Variables

A variable is a named container that stores data, that can be used later in program.

3 methods of declaring: var, let and const. var is old method whose value canbe changed. let is modern whose value canbe changed. const is constant value, it cant be changed.

JS has dynamic typing, it automatically undeestand the data type of a value. No need to declare it

JS has 8 datatypes:
Strings (stores text)
Number ( stores integers and decimal numbers , no seperate int and float types in JS )
Boolean ( true or false )
Undefined ( A variable has been declared but no value is assigned )
Null ( represents empty value )
Object ( stores related data together; like dictionary )
BigInt ( Used for very large integers )
Arrays ( Arrays are technacally an object in JS , not seperate datatype )
