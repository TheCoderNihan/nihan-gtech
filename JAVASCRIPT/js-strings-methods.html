JS String Methods

String functions/methods are built-in JS methods used to inspect, modify, search, or extract parts of text.

Strings are immutable: Once a string is created, its original value cannot be changed; string methods such as toUpperCase(), replace(), and trim() return a new string instead of modifying the original string.

Common String Methods

  • text.length — Returns the number of characters in a string.
  • text.toUpperCase() — Converts all letters in the string to uppercase.
  • text.toLowerCase() — Converts all letters in the string to lowercase.
  • text.slice() — Extracts and returns a portion of a string.
  • text.replace() — Replaces the first matching occurrence of specified text.
  • text.includes() — Checks whether the string contains specified text and returns true or false.
  • text.trim() — Removes whitespace from the beginning and end of a string.
  • text.charAt() — Returns the character at a specified index.
  • text.split() — Splits a string into an array based on a specified separator.
