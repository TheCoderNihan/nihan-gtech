JS Arrays

Array is a data structure used to store multiple values in a single variable, where each value is accessed by an index.

Array Operations

  • array.length — Returns the number of elements in the array.
  • array.push("Kiwi") — Adds one or more elements to the end of the array.
  • array.pop() — Removes and returns the last element of the array.
  • array.unshift("Kiwi") — Adds one or more elements to the beginning of the array.
  • array.shift() — Removes and returns the first element of the array.
  • array[0] — Accesses the first element of the array using its index.
  • array[array.length - 1] — Accesses the last element of the array.
  • array[index] — Accesses an element using its index.
  • Array Methods
  • array.includes("Apple") — Checks whether the array contains a specified element and returns `true` or `false`.
  • array.indexOf("Apple") — Returns the index of the first occurrence of a specified element, or `-1` if not found.
  • array.join(", ") — Combines all array elements into a single string using the specified separator.
  • array.reverse() — Reverses the order of the elements in the array.
  • array.sort() — Sorts the elements of the array.
  • array.slice(1, 3) — Returns a portion of an array without modifying the original array.

push(), pop(), unshift(), shift(), reverse(), and sort() modify the original array.

slice() does not modify the original array; it creates and returns a new portion of the array.
