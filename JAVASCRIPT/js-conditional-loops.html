JS Conditional Loops

Loops keeps running when a condition is true and stops when the condition is false.

while loop checks the condition first , then run the code.

do...while runs the code atleast once, even if condition is false.

for loop is used when the start, condition and increment are known.

Syntax : for ( initialisation ; condition ; increment ) { //code }

do-while needs a semicolon(;) at the end of the while(condition) statement.

break is used to stop the current statement working and exit from the loop.

continue skips the current loop iteration and moves to the next iteration.

break and continue does not work in if-else statements. They only work with loops.

A variable declared inside a loop is block-scoped. Therefore, it only exists inside the loop.
