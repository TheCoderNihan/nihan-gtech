JS Classes

A Class is a blueprint or template used to create objects. "new" is used to create an object from a class.

A method is a function displayed inside a class. ".method_name()" is used to run the function.

A constructer is a special method. A constructor automatically runs when an object is created using new. Constructors are commonly used to initialize an object's data when it is created.

this: Refers to the current object and is commonly used to access or initialize its properties and methods.
Eg: constructor(name) {
this.name = name;}
Here "name" is the parameter recieved by the constructer, "this.name" property belongs to the object.
