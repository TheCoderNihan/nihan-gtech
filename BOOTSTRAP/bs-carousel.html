Bootstrap Carousel

A Bootstrap Carousel is a slideshow component that displays a series of images or content one after another.
id gives carousel a unique id that other buttons can refer to.
Indicators create small dot below the images to represent each slide.
Every slide has its own div element for easy styling.
d-block display slide as block element. BS recommends it so slides fills the available width properly inside the carousel.
The recommended image is proper landscape image , 1200*600 px.
